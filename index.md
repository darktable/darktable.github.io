### Open source projects
#### [Phanto](https://github.com/oculus-samples/Unity-Phanto)
* Might be the only public output from my time at Meta. Probably suffering from bitrot at this point, but it was a demo of how to build a game that interacts with the Scene API. It uses the scene mesh and semantic tags to help agents navigate your rooms.

#### [XR Gizmos](https://github.com/darktable/XRGizmos)
* I use this in projects regularly. There are other paid and open-source libraries that do similar stuff, but this API is just like Unity's Gizmos. It has some useful primitives like arrows and cube grids.

#### [SimpleJSON Fork](https://github.com/darktable/SimpleJSON)
* I'm the guy that shared the MiniJSON script with the Unity community back in the day. I've stopped using MiniJSON and switched to SimpleJSON. This is my personal fork that's stricter than the original project (throws exceptions for bad behavior). I also added some tests, Unity Pose type serialization, and some utility methods.
